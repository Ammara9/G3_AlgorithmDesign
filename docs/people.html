People

The team

Group 3, students in Introduction to Information Science at the University of Borås.

Team members

  • Jayeeta: data curation. Chose and cleaned the articles and prepared the XML file.
  • Ammara: algorithm design. Wrote the search algorithm in Python.
  • Thuy Bich Nhan Duong: website design. Made the Figma wireframes and style guide, and wrote the HTML and CSS.
  • Laura Laik: wrote the HTML for index.html (the homepage), worked with Ammara to link Python with the front end, and worked with Nhan on the CSS styling.

GitHub: shared by the whole group.

How we worked

  • Tools: GitHub, Figma, Excel and VS Code
  • Workflow: we work in one shared GitHub repository, use branches and pull requests, and review each other's work.

Meetings and teamwork

  • Info session: we brainstormed the topic, the research question and the problem to solve, and decided who would do what.
  • Next day: we clarified the questions, divided more work, and agreed that people who work closely together would hold separate meetings.
  • Jayeeta and Ammara: agreed what Ammara needs to start the algorithm, and what Jayeeta needs to send with the data.
  • Ammara and Laura: decided what we get from the results and what will be displayed on the index page.
  • Laura and Nhan: shared the current stage of the styling to avoid double work.
  • Every day: the group chat kept everyone up to date on changes, pull requests and urgent problems.

Why we divided the work this way

Nhan and Laura are both comfortable with HTML and CSS, so we split the website work. Laura codes the HTML and CSS for the index page (the homepage). Nhan lays out the other pages, which are mostly text.

Ammara is more comfortable with back-end work, so she writes the search algorithm in Python.

Jayeeta has strong data analysis skills, so she works with the XML files: choosing, cleaning and preparing the articles in articles.xml.
