People

The team

Group 3, students in Datalogical Thinking at the University of Borås.

Team members

Ammara Shakeel

Architect and algorithm design

Ammara is the architect of the project. On 19 October she created the GitHub repository, invited the group to it and set up the folder structure. On 21 October she wrote the search algorithm, which combines a keyword search with four optional filters.

On 26 October she fixed a duplicated loop that stopped the articles from rendering, and added the written algorithm design to the algorithm page.

Responsibilities

  • The Python search algorithm
  • The architecture and folder structure
  • The written algorithm page

Jayeeta Roy

Data curation

Jayeeta chose OpenAlex as the source and took a random sample of 100 articles from five publishers. She cleaned the sample to 84 articles and kept 50, ten from each publisher. She then converted the data to XML and handed it over to Ammara on 21 October.

She also wrote the text of the dataset page, which explains the choice of data, the citation counts and how we calculated citations per year.

Responsibilities

  • The data sampling, cleaning and XML file
  • The written dataset page

Thuy Bich Nhan Duong (Nhan)

Website design

Nhan set up the Figma style guide with colours, typography, spacing and icons, and drew the wireframes for every page. She designed and built the navigation bar, wrote the CSS for the page layouts, and added the hero sections to all pages.

On 27 October she checked and updated the dataset and algorithm pages so that their styling is consistent.

Responsibilities

  • The Figma style guide and wireframes
  • The navigation bar
  • The HTML and CSS for all pages except the homepage

Laura Laikunaite

How we worked

All four of us wrote the text on this people page.

  • Tools: GitHub, Figma, Excel and VS Code
  • Workflow: one shared GitHub repository, with branches and pull requests. Changes to the main branch are reviewed by at least one other member before they are merged.

Meetings and teamwork

  • 19 October: we first discussed the assignment.
  • 20 October: we met on Zoom to agree on individual responsibilities and the initial structure for the data.
  • 21 October: Jayeeta handed the XML dataset over to Ammara.
  • 22 October: Ammara handed the working search functionality over to Laura.
  • 23 October: we met on Zoom to decide on the HTML structure.
  • 26 October: we met to review the latest updates. Ammara fixed a duplicated loop, and we agreed what to update on the index page.
  • 28 October: we have our last meeting to finalise everything before publication.
  • Besides meetings: the group chat kept everyone up to date on changes, pull requests and urgent problems.
