People

The team

Group 3, students in Datalogical Thinking at the University of Borås.

Team members

Ammara Shakeel

Architect and algorithm design

Ammara set up the project repository and the structure, wrote the Python search algorithm and its documentation, and fixed the bug that stopped articles from displaying. She also helped get the project running on Render and prepared the navigation bar and the static index page for GitHub Pages.

Responsibilities

  • Created and managed the GitHub repository.
  • Designed and implemented the algorithm logic in Python.
  • Wrote and explained the algorithm documentation and HTML content on algorithem.html.
  • Bug fixing: Identified and fixed a bug while testing the application. A duplicated article loop in the HTML template caused rendering issues and warnings. Removed the redundant loop and tested the results to ensure that articles were displayed correctly.
  • Published the project on GitHub Pages as a static website and on Render as a functional Flask application with Python-based search functionality.
  • A static navigation bar hardcoded in for Gihub pages in every html pages in docs
  • A static HTML version of the index page for GitHub Pages, showing the page design and structure without the Python functionality

Jayeeta Roy

Data curation

Jayeeta chose OpenAlex as the source and took a random sample of 100 articles from five publishers. She cleaned the sample to 84 articles and kept 50, ten from each publisher. She then converted the data to XML and handed it over to Ammara on 21 October.

She also wrote the text of the dataset page, which explains the choice of data, the citation counts and how we calculated citations per year.

Responsibilities

  • The data sampling, cleaning and XML file
  • The written dataset page

Laura Laik

Homepage writing, HTML and CSS

Laura wrote the text of the homepage, including the introduction, project purpose, dataset overview and workflow, and built its HTML and CSS. On 21 October she combined it with Ammara's search form. On 22 October she finished the homepage. On 26 October the group reviewed it in a meeting, and it was cleared of all remaining bugs.

She kept each page separate, so that every team member could work on their own page without editing the same file.

Responsibilities

  • The homepage HTML and CSS, with Ammara's content

How we worked

All four of us wrote the text on this people page.

  • Tools: GitHub, Figma, Excel and VS Code
  • Workflow: one shared GitHub repository, with branches and pull requests. Changes to the main branch are reviewed by at least one other member before they are merged.

Meetings and teamwork

  • 19 October: we first discussed the assignment.
  • 20 October: we met on Zoom to agree on individual responsibilities and the initial structure for the data.
  • 21 October: Jayeeta handed the XML dataset over to Ammara.
  • 22 October: Ammara handed the working search functionality over to Laura.
  • 23 October: we met on Zoom to decide on the HTML structure.
  • 26 October: we met to review the latest updates. Ammara fixed a duplicated loop, and we agreed what to update on the index page.
  • 28 October: we have our last meeting to finalise everything before publication.
  • Besides meetings: the group chat kept everyone up to date on changes, pull requests and urgent problems.
