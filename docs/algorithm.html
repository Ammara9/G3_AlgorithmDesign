Algorithm

How the search works

Our algorithm filters the 50 articles with your choices, then sorts them by citations per year.

What problem does it solve?

Which publishers' articles are cited most, and does it change with topic, year or open access? The algorithm lets you narrow down the 50 articles and see the most-cited ones first.

  • Input: the 50 articles in articles.xml, and your choices (keyword, topic, years, open access, sort order)
  • Process: check every article against your choices, then sort the ones that match
  • Output: a list of matching articles

How it works, step by step

  1. Load the 50 articles from articles.xml.
  2. Read your choices: keyword, topic, start year, end year, open access and sort order.
  3. Go through the articles one by one.
  4. Skip an article if it does not match your choices.
  5. Keep the articles that match.
  6. Sort them by citations per year, highest first, or put them in random order.
  7. Show the results.

The code

This is the Python code of our algorithm. It is the same code as src/search_articles.py. The numbers in the comments match the steps above.

import random
from src.read_xml import load_articles


def search_articles(keyword="", topic="", start_year="", end_year="",
                    open_access="", sort_by=""):

    articles = load_articles()          # 1. load the 50 articles
    results = []                        # empty list for the matches

    keyword = keyword.strip().lower()

    # 3. go through the articles one by one
    for article in articles:
        title = article.findtext("title", "").lower()
        topic_text = article.findtext("topic", "").lower()
        journal = article.findtext("journal", "").lower()
        keywords = [
            item.text.lower()
            for item in article.findall("keywords/keyword")
            if item.text
        ]
        year = int(article.findtext("year", "0"))
        access = article.findtext("open_access", "").lower()
        citations = float(article.findtext("citations_per_year", "0"))

        # 4. skip the article if the keyword is not found
        if keyword:
            searchable_text = [title, topic_text, journal] + keywords
            if not any(keyword in text for text in searchable_text):
                continue

        # 4. skip the article if it is not the chosen topic
        if topic and topic_text.strip() != topic.strip().lower():
            continue

        # 4. skip the article if it is outside the chosen years
        if start_year and year < int(start_year):
            continue
        if end_year and year > int(end_year):
            continue

        # 4. skip the article if open access is required and it is not
        if open_access == "true" and access != "true":
            continue

        # 5. keep the article and its citations
        results.append((article, citations))

    # 6. sort by citations per year, or shuffle into random order
    if sort_by == "citations":
        results.sort(key=lambda item: item[1], reverse=True)
    else:
        random.shuffle(results)

    # 7. return the matching articles
    return [article for article, citations in results]

Variables, selection and iteration

  • Variables: keyword, topic, start_year, end_year, open_access, sort_by and results
  • Selection: the if checks decide whether an article is kept or skipped
  • Iteration: the for loop goes through all 50 articles

Why we designed it this way

Filters are simple to explain and easy to check by hand. We sort by citations per year instead of total citations, because older articles have had more time to be cited, so this compares them more fairly.

Limitations: only 50 articles, and citation counts change over time.
